# Gest-o-Financeira
# Controle Financeiro

A ideia deste projeto é desenvolver um sistema de gestão financeira pessoal que permita ao usuário organizar, acompanhar e controlar melhor suas finanças.

O sistema tem como objetivo facilitar o registro de receitas e despesas, permitindo visualizar de forma mais clara para onde o dinheiro está sendo destinado. Também será possível organizar os lançamentos por categorias e formas de pagamento, além de acompanhar gastos realizados no cartão de crédito e compras parceladas.

A proposta é transformar informações financeiras que normalmente ficam espalhadas em anotações, aplicativos ou planilhas em um único sistema, proporcionando uma visão mais organizada da situação financeira.

Este projeto também faz parte do meu processo de aprendizado e desenvolvimento na área de programação, utilizando tecnologias como **Python, Flask, React e SQLite**, permitindo colocar em prática conceitos de desenvolvimento backend, frontend, banco de dados, APIs e organização de projetos.

O objetivo final é construir uma aplicação simples, funcional e intuitiva, que possa realmente ser utilizada no dia a dia para auxiliar no planejamento e no controle das finanças pessoais.
